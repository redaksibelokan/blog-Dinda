# Blog Adinda Destiana Aisyah — prototipe multipage

Ekstrak ZIP, lalu buka `index.html` melalui Chrome. Navigasi menggunakan file HTML terpisah; tidak memerlukan server untuk meninjau prototipe. Header dan footer sama di seluruh halaman.

`index.html`, `karya.html`, `tentang.html`, `kontak.html`, `artikel/*.html`, `assets/site.css` dan aset gambar.

`articles.json` merupakan data awal untuk persiapan integrasi CMS/GitHub; halaman artikel saat ini merupakan HTML statis, sehingga perubahan JSON saja belum otomatis membangun ulang halaman. Belum ada CMS atau deployment. Sembilan karya asli belum memuat naskah lengkap. Contoh pembacaan diberi label demonstrasi. Narasi profil merupakan usulan editorial untuk ditinjau.

Revisi editorial: narasi menggunakan sudut pandang orang pertama, email pada header dan hero, akun sosial pada footer dan halaman kontak. Logo transparan juga digunakan sebagai favicon. Narasi profil adalah usulan penulis untuk disetujui, bukan kutipan terverifikasi.

Revisi: hamburger interaktif pada seluruh header dan panel hero desktop; ukuran hero diperkecil tanpa mengubah rasio gambar. Versi ponsel memakai potret lebih ringkas.
